# My Beamer Template

A customisable Beamer presentation template.

## Usage

This repository is designed to be added as a **git submodule** to your presentation projects. This allows you to maintain a consistent base template while customising it for each specific presentation.

### Adding as a Submodule

```bash
git submodule add git@github.com:RyanBalshaw/my-latex-presentation-template.git beamer-presentation
```

### Updating the Submodule

To pull the latest changes from the template:

```bash
git submodule update --remote
```

## Customisation

After adding the submodule, you can customise the template for your specific presentation needs while keeping the base template in sync with upstream changes.
